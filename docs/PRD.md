# 产品范围

Finder Fixer 只解决一个问题：让后续新开的标准 Finder 窗口使用统一的宽高，减少反复手动调整。

## 行为约定

- 默认 1000 × 700 pt，自动应用开启。宽高为外框逻辑点，输入 100–10000 整数。
- 新窗口自动调整一次，既有窗口和手动缩放后的窗口保持原状。
- 保存设置、重新开启自动应用、授权恢复和应用启动均不批量调整已有窗口。
- 标签页、重新聚焦、最小化恢复不触发重复调整。
- 系统最小尺寸和屏幕可用区域可限制实际结果，不反写用户偏好。
- 未授权时展示系统权限入口；已授权时可编辑尺寸及开关。
- 关闭设置后保持运行，菜单退出停止监听。

## 范围边界

包含原生菜单栏、设置校验、本机偏好持久化、Finder 生命周期重连和屏幕几何适配。

暂不包含最后尺寸学习、按文件夹记忆、其他应用管理、位置记忆、登录启动、自动更新和云端服务。对平铺／最大化窗口不承诺统一识别。部署目标与实机验证范围分别以 [README](../README.md) 和[测试说明](manual-testing.md)为准。

## 验收原则

核心流程：设置尺寸 → 新建窗口 → 实际尺寸匹配或受到可解释的系统约束 → 手动缩放不被拉回。

组件测试证明策略与状态行为；实际 Finder 操作证明桌面集成。两类证据独立记录，不将计划或未执行场景标为通过。
