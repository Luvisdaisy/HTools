# HTools v0.2.1 产品范围

面向使用访达与外接键盘的 Mac 用户，减少窗口尺寸重复调整和内置键盘误触。

- 访达窗口：固定宽高，按新窗口应用一次，可关闭。保留手动缩放，不批量改已有窗口。
- 键盘控制：检测设备、保守分类、显式开关；默认关闭、不持久化禁用状态。
- 权限设置：统一首次配置，前台权限、服务连接和实际后台权限均需核实；支持更新、修复与移除服务。
- 交互：原生中文界面、菜单栏常驻、浅色/深色适配。未授权功能页仅有权限入口。

不包含自动禁用、登录启动、自动更新、云服务、按键记录、虚拟 HID、DriverKit、其他应用窗口管理。发布为临时签名通用 DMG 预览版。

产品完成情况与测试边界以 [manual-testing.md](manual-testing.md) 为准。
