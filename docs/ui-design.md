# 界面约定

应用使用 AppKit 菜单栏和 SwiftUI 单页设置。内容区 432 × 280 pt，24 pt 内边距，使用系统字体、语义配色与原生控件。当前语言为简体中文。

菜单栏使用 `MenuBarIcon` 彩色资源，菜单仅包含“设置”和“退出”。设置窗口复用；最小化后重新打开会恢复并置前。关闭窗口后应用继续在菜单栏运行。

## 已授权

显示 Finder Fixer 标题、宽度与高度输入、pt 单位、保存按钮及自动应用开关。无修改或输入非法时禁用保存；非法输入显示原因与放弃修改入口。不展示成功提示、窗口清单或手动调整功能。

## 未授权

标题下方居中显示“前往设置辅助功能权限”。尺寸表单隐藏，检测到权限变化后自动切换。未授权时关闭窗口或退出不会验证、保存隐藏草稿。

## 可访问性

宽高控件带逻辑点可访问名称，开关保留完整标签。键盘和 VoiceOver 的实际覆盖情况参阅[测试说明](manual-testing.md)，代码属性不等同于实机验证。
