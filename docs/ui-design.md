# HTools 界面与流程

760 × 520 的原生设置窗口，196 pt 侧栏。顶部显示应用标识，访达和键盘为功能导航；底部为带待配置指示的权限入口与版本号。使用系统背景、蓝色选择态、圆角卡片、SF Rounded 标题及系统正文，深色模式跟随系统。

- 访达：标题和用途说明；宽高、保存状态、自动应用集中在一张卡片；错误就地提示。离开时保存有效草稿，非法草稿不被隐藏。
- 键盘：只保留设备列表与开关区域；列表可滚动，名称最多两行，分类明确；开关附近显示正常、连接中、禁用或恢复中。
- 权限：0–3 完成进度；每项说明用途与下一步，区分安装、更新、后台未就绪；管理菜单可重装或移除服务。系统授权期间避免重复操作和退出。
- 未授权功能页：保留标题，正文仅显示“前往权限设置”。
