# 使用与故障排查

## 安装

当前发布源码测试版。安装完整 Xcode 后，按 README 克隆项目，运行 `./scripts/build.sh`。在 Finder 中打开 `build/Build/Products/Release/`，可将 `finder-fixer.app` 复制到“应用程序”目录，再打开并授权该固定位置的应用。不要同时运行多个副本。

应用使用 ad-hoc 临时签名，没有 Developer ID 签名或公证。不提供关闭 Gatekeeper、修改 TCC 数据库等绕过系统安全机制的安装步骤。

## 日常使用

首次启动展示设置。未授权时点击“前往设置辅助功能权限”，手动添加并开启当前 App。返回应用后，表单会自动显示。

宽高接受 100–10000 的整数，单位为窗口外框的逻辑点 pt。点击保存，只影响之后新开的窗口。已授权时关闭设置会保存有效草稿；非法草稿需要改正或放弃。未授权时隐藏草稿不会阻止关闭。

默认值为 1000 × 700，默认开启自动应用。应用启动时已有窗口保持原状；新窗口调整一次后可自由拖动。没有文件夹记忆、手动批量应用或尺寸锁定功能。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 授权列表已开启，但仍显示授权按钮 | 确认授权对应正在运行的副本；重新构建后可能要移除旧条目，再添加当前 App |
| 保存后窗口没变 | 保存不会调整已有窗口，请新开标准 Finder 窗口测试 |
| 新窗口没有调整 | 检查自动开关与授权；排除全屏、最小化、系统平铺和创建时鼠标拖动；关闭后新建窗口重试 |
| 小尺寸与输入不一致 | Finder 自身最小尺寸会限制结果，原始偏好不会因此改变 |
| 重启电脑后不生效 | 暂无内置登录启动，请先手动启动应用 |
| 关闭设置后仍然运行 | 这是菜单栏工具；需要完全停止时在菜单中选择“退出” |

应用内部会重连 Finder 进程并处理权限恢复，但监听建立期间无法确认的新窗口可能被当作已有窗口，不保证追补调整。错误诊断目前主要保留在内部状态和本机日志，界面不展示完整故障详情。

## 重置与卸载

先退出应用。若确实需要清除所有设置，可执行：

```sh
defaults delete local.finder-fixer
```

该命令仅删除本应用的偏好，包括宽高和自动开关。普通卸载只需删除 App，并在辅助功能设置中移除对应条目；源码目录和构建产物可按需删除。
