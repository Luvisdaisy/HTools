# HTools 使用指南

## 首次安装

按 [INSTALL.md](../INSTALL.md) 从 DMG 安装到“应用程序”。首次权限页显示三项配置与完成进度：辅助功能用于访达；输入监控用于键盘；键盘控制服务在安装时需要管理员确认。返回 HTools 后自动检查，不必反复点击。系统要求重启时，先退出再打开。

三项就绪后点击“开始使用”。未配置的访达和键盘页仅显示“前往权限设置”；也可随时点击面板顶部的“权限设置”标签。通用设置始终可用。

## 打开与收起

左键点击菜单栏图标开合固定面板；右键菜单只有“设置”和“退出”两项纯文字。面板无窗口控制按钮，不可拖动；Esc、⌘W 或点击外部可收起。无效尺寸草稿或系统服务授权进行中会暂缓收起。

## 开机自启

打开“通用设置” → “开机自启”，下次登录 Mac 后自动在菜单栏运行。默认关闭，可随时取消；该开关由 macOS 登录项管理，不需要键盘服务或辅助功能权限。

如显示等待批准，点击“前往系统登录项设置”并允许 HTools；从系统设置返回或重新打开面板会同步真实状态。失败时按页面错误提示检查，将 App 安装在“应用程序”并从该副本开启。自启不会恢复上次的键盘禁用状态。

## 访达窗口

输入 100–10000 的整数宽高，单位为窗口外框逻辑点 pt。点击保存后按钮显示“已保存”。新开标准窗口验证；保存不会调整已有窗口。自动应用可关闭，手动缩放不会被拉回。

离开页面或收起面板时保存有效草稿；非法草稿需改正或放弃，不会悄悄丢失。访达自身最小尺寸和屏幕可用区域可能限制最终尺寸。全屏、最小化及非标准窗口被跳过。

## 键盘控制

核对内置键盘分类后开启“禁用内置键盘”，不要求连接外接键盘。连接或恢复过程中暂时不可重复操作；只有真实 seize 成功才显示已禁用。无法识别唯一可信内置键盘时开关不可用。

外接键盘断联后仍保持禁用，可用鼠标或触控板关闭开关恢复。退出、内置目标移除、睡眠和会话失活会结束本次会话；不会自动再次禁用。电源与 Touch ID 不在保证范围内。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 权限已开启但页面仍有入口 | 确认系统授权对应正在运行的 HTools；重建或更新后可能需重新添加 |
| 显示“更新服务” | 权限页点击更新，完成系统授权；服务需与当前 App 匹配 |
| 后台输入权限未就绪 | 确认当前 App 输入监控权限，按系统提示重启，再检查；保留完整错误文本 |
| 错误 0xe00002e2 | 系统拒绝设备访问，可能是后台输入权限；仅前台授权不代表后台允许 |
| 新窗口尺寸不变 | 检查辅助功能和自动应用；使用新建标准窗口，已有窗口不会改变 |
| 未能识别唯一可信的内置键盘 | 检查设备分类与权限；虚拟和歧义设备不会被独占，外接键盘不影响开关 |
| 开机自启等待批准或失败 | 将 App 放入应用程序，在通用设置检查错误或打开系统登录项设置 |
| 收起面板后仍运行 | 菜单栏工具的正常行为；从菜单栏退出 |

## 更新和卸载

更新前退出应用，替换到同一安装位置，再按权限页提示更新服务。不要同时运行开发版和安装版。

卸载前在通用设置关闭开机自启，再进入权限页 → 管理服务 → 移除服务，完成系统授权；随后退出、删除 App，在系统隐私设置移除对应条目。普通卸载保留窗口偏好；需要重置时退出后执行 `defaults delete local.HTools`。

问题反馈请提供版本、系统、芯片和完整错误文字；不要公开私人文件名、输入内容或完整系统日志。
