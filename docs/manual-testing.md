# HTools v0.2.0 验证范围

## 已有证据

- 2026-10-03，用户明确确认修正后台用户会话后的 HTools 集成键盘功能“可用”。本机为 Apple Silicon / macOS 26.6.2。该反馈未逐项确认所有断连、睡眠及崩溃情境。
- 之前独立 POC 有 seize/release API 与四项实体操作确认：内置普通键/修饰键屏蔽、外接输入正常、触控板正常、释放后内置恢复。这些结果只属于 POC。
- 15 项共享 KeyboardCore 分类/生命周期测试通过。
- 34 项 XCTest 覆盖尺寸、草稿、偏好迁移、保守设备筛选、IPC、签名要求、权限门槛及会话启动参数。测试不安装服务、不执行真实键盘独占。
- v0.2.0 的 UI 使用实际 SwiftUI 组件离屏渲染检查，含首次权限、访达、键盘、未授权与深色状态；示例状态不能当作实机截图。
- Release、通用架构、严格签名与 DMG 校验按发布流程执行；GitHub CI 运行同一构建与测试脚本。原始本机日志留在 `build/` / `output/`，不上传。

旧版出现 `0xe00002e2` 时，系统明确记录后台 TCC 拒绝。修正后使用 `launchctl asuser` 保留 root 身份并采用登录用户审计会话，同时检查真正 worker 权限。用户之后确认可用，不将旧版失败隐去。

## 发布后仍需覆盖

Intel、旧 macOS、多屏、完整 VoiceOver，以及 USB/蓝牙断连、GUI 无响应/崩溃、睡眠和会话切换的系统化物理恢复矩阵。新 UI 与发布安装包不自动继承此前所有硬件情境的验证结论。

## 手工验收

1. 安装到“应用程序”，按系统提示打开并完成三项权限；取消、拒绝和重启后状态准确。
2. 访达输入有效/无效尺寸，保存、切页、关闭；仅后续新窗口调整一次。手动缩放、标签、全屏和最小化结果分别记录。
3. 核对内外键盘，开启后确认无需重复管理员授权；实体确认内置、外接、触控板与手动释放。
4. 分别测试外接断连、退出、强制结束 GUI、睡眠/唤醒。每项确认内置恢复且不自动重新禁用。模拟输入不能代替实体输入。
5. 撤销权限后控件隐藏；更新 App 后旧服务被识别为需更新；移除服务后访达偏好保留，键盘正常。

运行 `./scripts/test.sh` 和 `swift test --package-path KeyboardGuardPOC` 获取组件测试。运行 `./scripts/render-ui-previews.sh` 更新离屏预览。请分别记录自动化、API 和人工观察，不用其中一类替代另一类。
