## 手工回归流程

请使用临时 Finder 窗口，并记录系统版本、芯片、显示器和缩放。测试前记下原偏好，结束后恢复。

| 步骤 | 预期 |
| --- | --- |
| 启动应用并授权 | 未授权显示入口；授权后自动显示尺寸表单 |
| 保存 1200 × 700，新建窗口 | 外框尺寸匹配，或记录 Finder/屏幕的实际约束 |
| 手动拖成其他尺寸 | 不被拉回，固定偏好不改变 |
| 保存不同尺寸 | 既有窗口保持，下一个新窗口使用新值 |
| 关闭并重新开启自动应用 | 关闭时不调整；重新开启不调整既有窗口 |
| 新标签页、切换焦点、最小化恢复 | 不重复应用尺寸 |
| 退出重开 | 偏好保留，已有窗口保持 |
| 撤销并恢复权限 | 停止控制、显示入口；恢复后重建基线 |
| 授权撤销时保留非法草稿并关闭 | 不被隐藏表单阻止关闭，不保存非法值 |
| 全屏、系统平铺、快速开关窗口 | 记录跳过行为、系统限制、异常或遗漏，不预设全部通过 |
| 多屏、小屏、不同缩放 | 校验屏幕选择、位置可见性及原偏好保持 |

不要用 AX 探针代替应用写入后再声称应用成功。可选 `scripts/ax-probe.swift` 用于独立读数与事件观察；`--resize` 会主动改变窗口，只应用于单独的 API 调试，不属于应用验收。
