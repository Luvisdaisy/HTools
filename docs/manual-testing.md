# HTools 验证范围

## 2026-10-18 开机自启与手动键盘控制

本轮增加通用设置的系统登录项开关，并移除集成版外接键盘前置条件和断联释放逻辑。本机 Apple Silicon / macOS 27.0.1 / Xcode 27 的组件及构建验证：

- 44 项应用 XCTest、15 项共享 KeyboardCore 测试通过。登录项使用注入服务覆盖注册、移除、待批准、失败、外部修改和未找到应用；不写入真实系统登录项。模拟 HID 覆盖无外接启动、全部外接移除仍禁用、目标移除释放、手动释放/重开及歧义拒绝；POC 继续验证显式外接断联释放。
- Release 构建及 `codesign --verify --deep --strict` 通过；工程重新生成结果一致；`git diff --check` 和本次 OpenSpec 严格校验通过。
- 14 个实际 SwiftUI 组件离屏预览已生成，检查通用页、待批准、错误浅深色、无外接开启前/已禁用及原有页面的文字和布局。预览不连接服务、不枚举实际设备、不修改登录项。

尚未实际注册本机登录项、重新登录或通过实体键盘验证本轮无外接/断联保持行为。历史 v0.2.x 和 POC 反馈不替代这些验收。构建和测试最初受沙箱的图标服务/缓存访问限制，沙箱外重跑成功；没有通过更改系统权限数据库绕过授权。

以下 2026-10-04 的测试数量与实机反馈属于历史版本。

## 自动化与资源验证

2026-10-04，本机 Apple Silicon / macOS 26.6.2 / Xcode 27：从干净缓存运行 34 项 XCTest 与 15 项共享 KeyboardCore 测试，均通过。覆盖尺寸、草稿、偏好迁移、保守设备筛选、IPC、签名要求、权限门槛及会话启动参数；测试不安装服务、不执行真实键盘独占。

CI 使用 macOS 26 / Xcode 26.6，检查工程生成一致性、通用架构 DMG 打包、应用测试与共享核心测试。发布包需检查严格签名、arm64/x86_64、DMG 完整性以及 SHA-256，按 [发布流程](../RELEASING.md) 执行。

Flow 图标的原生资源编译、兼容 `.icns`、1024 px 图像及浅色/深色菜单模板已检查。紧凑面板使用实际 SwiftUI 组件离屏渲染，覆盖首次配置、配置完成、访达、无效尺寸、键盘、未授权和深色状态；示例状态不能当作实机授权或硬件测试证据。

## 已有实机证据

- 2026-10-04，紧凑面板开发构建已在本机运行。辅助功能树显示“弹出窗口”，无关闭、缩放或最小化按钮；实际操作了标签切换、未授权入口、Esc 和 ⌘W 收起。截图观察到顶部箭头与紧凑布局。
- 菜单栏真实左右键、拖拽不分离、多屏定位尚未完成自动化实机验证。工具未提供图标的可访问元素，桌面截图也未返回菜单栏合成画面；不将代码路径与构建成功当作这些交互的验收证据。
- 更新临时签名构建后，系统隐私授权和签名匹配的键盘服务需重新核实。开发构建曾显示 0/3 和“更新服务”；安装新版本不代表自动获得全部权限。
- 2026-10-03，用户确认修正后台用户会话后的 HTools 集成键盘功能“可用”。该反馈属于 v0.2.0 阶段，未逐项确认全部故障恢复情境，也不等于 v0.2.1 的实体键盘重新验收。
- 独立 POC 曾确认内置普通键/修饰键屏蔽、外接输入与触控板正常、释放后内置恢复；这些结果只属于 POC。

旧版 `0xe00002e2` 曾有后台 TCC 拒绝记录。当前使用 `launchctl asuser` 保留 root 身份并采用登录用户审计会话，检查实际 worker 权限。API 路径与人工结果分别记录。

## 仍需覆盖

Intel、旧 macOS、多屏、菜单栏自动隐藏、全屏空间、不同缩放、完整 VoiceOver，以及 USB/蓝牙断连、GUI 无响应/崩溃、睡眠和会话切换的系统化物理恢复矩阵。新 UI 与安装包不会自动继承以前所有硬件情境的验证结论。

## 手工验收

1. 从发布 DMG 安装到“应用程序”，确认只有一个主应用副本；核对版本、签名与发布包一致。必要的 `HToolsKeyboard.app` 是后台服务，不是第二份主应用。
2. 完成辅助功能、输入监控及服务更新；检查取消、拒绝和重启后的状态。
3. 左键开合、右键两项纯文字菜单，Esc / ⌘W / 外部点击收起；固定于图标下方，无窗口控制按钮、不能拖拽分离。
4. 访达输入有效/无效尺寸，保存、切页、收起；无效草稿需修正或放弃。仅后续新窗口调整一次，分别记录手动缩放、标签、全屏和最小化。
5. 更新服务后，不连接外接键盘，核对唯一可信内置键盘并开启；实体确认内置禁用、触控板正常、鼠标手动关闭可恢复。再连接外接键盘开启，确认外接输入正常。隐藏面板不会改变禁用状态。
6. 禁用期间断开全部 USB/蓝牙外接键盘，确认开关仍开、内置仍禁用，重连后保持状态；手动关闭后恢复。再分别测试退出、强制结束 GUI、睡眠/唤醒及会话切换，确认这些情况内置恢复且不自动重新禁用。模拟输入不能代替实体输入。
7. 撤销权限后控件隐藏；升级后旧服务提示更新；移除服务后访达偏好保留、键盘正常。
8. 通用设置在未授予辅助功能/输入监控时仍可用。开启自启，核对系统登录项及待批准入口；重新登录后确认只有一个菜单栏实例、键盘开关关闭。关闭自启后再次登录不启动；系统设置中修改后返回应用会同步状态。拒绝/失败时不假报成功，卸载前关闭自启。

运行 `./scripts/test.sh`、`swift test --package-path KeyboardGuardPOC` 获取组件结果，运行 `./scripts/render-ui-previews.sh` 更新离屏预览。原始本机日志与硬件证据不上传公开仓库。发布后只保留当前安装包、校验和及简短本机审查记录，清理重复构建与旧安装副本。
